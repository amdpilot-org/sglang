SGLang 쿡북은 프로덕션 환경에서 SGLang을 배포하고 사용하는 방법을 설명하는 커뮤니티 기반 실전 가이드 모음입니다. 목표는 **"하드웨어 Y에서 작업 Z를 위해 SGLang과 관련 모델을 어떻게 사용하는가?"**라는 질문에 명확하고 실행 가능한 답을 제공하는 것입니다.

<Note>
  한국어 번역은 현재 시범 운영 중입니다. 아래에 표시된 페이지만 한국어로 제공되며, 나머지 쿡북은 언어 선택기에서 English를 선택해 확인할 수 있습니다.
</Note>

## 번역된 가이드

<Card

## 번역에 참여하기

한국어 쿡북은 원문과 나란히 관리합니다. 번역을 추가하거나 수정하려면 [현지화 기여 지침](https://github.com/sgl-project/sglang/tree/main/docs#localizing-the-cookbook)을 확인하세요. 명령어, 모델 ID, API 필드 이름은 번역하지 않으며 한국어 원어민 검토를 권장합니다.
